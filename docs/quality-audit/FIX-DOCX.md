# 워드(docx) 표시 품질 고치기 — 결과 보고 (가지 `office-quality-docx`)

작성 2026-11-20 · 출발점 `94ab62b`(점검 보고서 REPORT.md) · 작업 폴더 `projects/webviewer-q-docx`
**2차(적대적 검토 REVIEW-DOCX 반영)는 8절** — 1~7절 중 2차에서 바뀐 내용은 그 자리에 고쳐 적었다.
운영 폴더·운영 포트(8000/8010)·MS Office는 건드리지 않았다. 시험 서버는 이 작업 폴더에서 8143(손 점검)·8153(audit)으로,
전용 데이터·임시·LibreOffice 프로필(`.audit-run/`)로 따로 띄우고 번호(PID)로만 껐다. 정답 PDF는 점검 때 만든 것을 복사해 썼다
(`npm run audit:office -- --only docx --no-office` — `--no-office`는 정답이 없으면 Office를 띄우지 않고 멈춘다).

## 2. 고친 방법(구조)

- **원본 그대로 보존(손실 없는 왕복)**: 편집기가 직접 고치지 않는 요소 — 그림·글상자·도형·차트·필드(PAGE·목차 등)·각주/미주 참조·책갈피·
  수식·변경 내용 삭제분·내용 컨트롤(w:sdt) — 는 `ooxml`(글 안)·`ooxml_block`(본문 직속) 노드에 **원본 XML 그대로** 담고, 화면에 필요한 값
  (그림 경로·크기·떠 있음, 글상자 안 문단, 필드 결과 글자, 각주 번호)만 따로 둔다. 저장 때 원본 XML을 그대로 쓴다.
- w:pPr·w:rPr·w:tblPr·w:trPr·w:tcPr 중 모델링하지 않는 자식(번호 numPr·탭·문단 테두리·구역 sectPr·keepNext·문자 스타일·표 스타일·
  제목 행 반복 등)도 노드 속성에 원본 그대로 담고, 저장 때 스키마 순서로 합친다(`src/docx/ooxml.ts` `prXml`). 원본 `w:document` 여는 태그
  (네임스페이스 전부)를 그대로 쓴다.
- **보존 조각 저장소(2차)**: 원본 XML은 노드에 싣지 않고 서버의 저장소(해시 → XML, `room.docxFragments`, 방이 열려 있는 동안 유지)에 두고 노드엔
  "태그@해시" 참조만 싣는다. Yjs로 들어온 값은 서버가 검사하지 않지만, 저장소에 없는 참조는 저장 때 버려지므로 다른 참여자가 임의 XML
  (INCLUDEPICTURE 등)을 보낼 길이 없다. 지운 뒤 자동저장되고 되돌린 조각도 저장소에 남아 다시 저장된다(검토 C3). 그림은 `/api/view/slide-media`가
  `word/media/` 바로 아래 파일만, docx 문서의 토큰으로만 내려준다(경로 형식·문서 종류 확인).
- **화면 장식**(`src/client/docxLayout.ts`, 문서 내용이 아니라 저장에 안 들어감): 번호 글자, 쪽 경계(각주·바닥글·쪽 간격·머리글),
  탭 폭 계산, 문서 스타일 → CSS.

## 5. 고칠 수 없는 요소로 남긴 것(보이지만 편집기에서 내용을 못 고침, 저장 땐 원본 그대로)

그림(선택·삭제·잘라 옮기기·같은 문서 안 복사는 됨), 글상자·도형·차트·도형 묶음(EMF/WMF·차트·도형은 서버가 LibreOffice로 그린 그림으로 보임),
필드(쪽 번호·목차·하이퍼링크 필드 — 결과 글자가 보임), 각주/미주 참조와 본문, 머리글·바닥글, 내용 컨트롤(w:sdt)·사용자 XML 블록, 수식,
변경 내용 삭제분(빨간 취소선 글자). 변경 내용 **삽입**(w:ins·w:moveTo)·하이퍼링크·스마트 태그는 글자를 고칠 수 있고 감싸개는 그대로 저장된다
(2차 — 1차에선 삽입이 "수락"됐다). 저장하면 사라지는 것이 남지 않아 저장 손실 경고는 없앴다.

## 7. 확인하지 않은 것

실제 Word로 저장본을 열어 보지는 않았다(규칙상 Office를 띄우지 않음) — 저장본 XML 검증(올바른 XML·요소 개수·두 번 저장 동일)과
LibreOffice 재변환(저장 후 보기 화면 PDF가 정상 생성)으로 대신했다. 같은 abstractNum 번호 이어 세기(I6)와 koreanLegal(Minor 9)도 Word로는
확인하지 못했다(LibreOffice는 같은 결과). 큰 문서 입력 속도는 8절에 쟀다. 고객 문서는 쓰지 않았다.
