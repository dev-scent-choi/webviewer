작성 2026-11-22. 가지 `office-artcraft`(136cbcd 위). 사용자 결정: "아트크래프트 도구 UI로 변경하고 기능을 동일하게 입히자. 열기/편집 모드는 같은 화면, 도구 활성/비활성 차이만." 앱 임베드 방향(2026-11-22-artcraft-app-screen-design.md)은 **폐기**.

## 1. 기준 디자인
아트크래프트 웹 앱 캡처(`C:\Users\OpenMinds\projects\artcraft-eval\spike-webapp\shots\{word-report,grid-plain,deck-korean}.png`) — 데스크톱 오피스형 리본:
- 제목 줄(24px, 어두운 바탕 아님 — 밝은 회색): 왼쪽 자동 저장 토글·빠른 실행(저장·되돌리기·다시 실행), 가운데 문서 이름, 오른쪽 검색·메모·편집/보기 모드 단추·공유·사용자 원.
- 탭 줄(22px): 파일 · 홈 · 삽입 · 그리기 · 디자인 · 레이아웃 · 참조 · 편지 · 검토 · 보기 … (앱마다 다름) — 밑줄 강조.
- 리본 본체(62px): 묶음(클립보드·글꼴·단락·스타일·편집 …)마다 큰 아이콘+이름 단추와 작은 단추 열, 묶음 이름이 아래 작은 글씨, 묶음 사이 세로 구분선, 오른쪽 아래 작은 "자세히" 화살표.
- 워드는 눈금자, 엑셀은 이름 상자+수식 줄, PPT는 왼쪽 섬네일 레일.
- 상태 줄(18px): 왼쪽 쪽/단어 수·언어, 오른쪽 보기 전환 아이콘·확대 슬라이더·%.
- 높이는 캡처 실측(2026-11-22, 1400×900 캡처 기준): 제목 줄 24 · 탭 줄 22 · 리본 62 · 상태 줄 18px. 처음 적은 추정치 28/24/90/22는 틀려서 고침. 리본 62 = 작은 단추 16px 세 줄(48) + 묶음 이름 줄 14, 큰 단추 48px(아이콘 24px), 글자 10~11px.
- 색: 밝은 회색 틀(#f3f3f3 ~ #fafafa), 선택 탭·강조는 앱 색(워드 파랑, 엑셀 초록, PPT 주황), 아이콘은 단색 선 아이콘.

## 2. 하는 일
1. `src/client/officeShell.ts`·`ribbonMenus.ts`·`public/editor*.html`·`public/css/style.css`의 리본 **모양**을 위 규격으로 바꾼다: 제목 줄·탭 줄·리본 본체·묶음·상태 줄의 높이·간격·글자 크기·색·아이콘 크기, 큰 단추(아이콘 위, 이름 아래)와 작은 단추의 구분, 묶음 이름 줄, 구분선, "자세히" 화살표(동작은 기존 대화상자/패널 열기).
2. **기능·id·단축키·탭 구성은 그대로.** 단추를 더하거나 빼지 않는다. 지금 우리 리본에 있는 묶음·단추를 아트크래프트 묶음 이름과 순서에 맞춰 **배치만** 다시 한다(없는 묶음은 만들지 않음).
3. 글자는 전부 한글(탭·묶음·단추 이름·말풍선·상태 줄). 아트크래프트의 영어 이름은 참고만.
4. 읽기 전용(ui=view)은 지금 규칙 그대로: 같은 화면, 쓰는 단추만 흐림(`.ro-disabled`). 새 디자인에서 흐림이 고르게 보여야 한다.
5. 리브레오피스 보기 화면(`/view.html`) 도구 막대도 같은 제목 줄·탭 줄·리본 규격으로(묶음: 보기·찾기·쪽·인쇄·내려받기·편집 열기), 단추 id 유지.
6. 600px: 리본은 가로 스크롤 없이 묶음이 접히거나(아이콘만) 줄 바꿈, 제목 줄은 한 줄.

## 3. 하지 않는 것
- 새 기능·새 단추, 아트크래프트 앱 임베드, 앱 메뉴 한글화, 아이콘 세트 교체(기존 아이콘 유지, 크기만 조정; 없는 아이콘은 기존 방식으로).
- 향기랩 경로의 동작 변경(모양만 바뀜 — 이는 의도된 변경).

- 새 스크린샷 비교 검사 `scripts/verify-ribbon-skin-e2e.mjs`: 세 편집기 + 보기 화면에서 제목 줄·탭 줄·리본·상태 줄의 높이가 규격(24/22/62/18px ±2, 캡처 실측 2026-11-22)인지, 묶음 이름·탭 이름이 한글인지(영문자만 있는 라벨 0), 큰 단추의 아이콘-이름 배치, 읽기 전용 흐림, 600px 가로 스크롤 없음.
