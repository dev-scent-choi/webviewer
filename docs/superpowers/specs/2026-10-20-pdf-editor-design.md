# PDF 편집기 (pdfcraft 같은 화면) — 설계

- 날짜: 2026-10-20
- 요청: "pdf도 아트크래프트 프로젝트 중 하나를 이용해서 비슷하게 만들어줘" → "pdf craft는 아니고 유사하게 만드는 거야"
  — ArtCraft의 PdfCraft(storytold/pdfcraft)를 **가져다 쓰지 않고**, 그 화면·기능과 비슷한 PDF 편집기를 webviewer에 직접 만든다
  (워드·엑셀·PPT 편집기를 오피스처럼 직접 만든 것과 같은 방식). pdfcraft 웹판은 앱 화면·입력 글꼴에 한글이 없어
  메모·양식에 한글을 넣으면 □로 깨지고, 글꼴이 안 들어 있는 한글 PDF는 글자를 그리지 않았다(2026-10-20 확인).
- 사용자가 고른 것: **webviewer 서버를 거쳐서**(다른 오피스 문서와 같은 업로드·토큰·저장 흐름), **화면은 pdfcraft처럼**(한국어 문구),
  1차 범위 **보기·찾기 + 주석 + 페이지 정리 + 양식 채우기·서명** 전부.
- 참고 화면: pdfcraft README의 스크린샷(viewer, organize, forms, find, bookmarks) — 배치와 동작만 참고하고 아이콘·이미지·문구는 가져오지 않는다.

## 1. 화면 (editor-pdf.html)

pdfcraft의 배치를 따른다. 모든 문구는 한국어.

```
┌ 제목 줄: ← (다른 파일 열기) │ 문서 탭(파일 이름·저장 상태 점) ··········· 연결됨 · 참여자 ┐
├ 위 줄: [≡ 메뉴] 모든 도구 · 읽기 · 편집 · 서명          [🔍 문서에서 찾기 Ctrl+F] ⓘ 💾 🖨 ┤
├──────────────┬──────────────────────────────────┬────────────────┬──┤
│ 모든 도구     │ ┌─┐                               │ 정보 창         │책│
│  주석 달기    │ │↖│   (페이지들 — 연속 스크롤)       │ (책갈피 / 페이지 │갈│
│  페이지 정리  │ │✋│                                 │  / 메모 / 필드)  │피│
│  파일 합치기  │ │💬│                                 │                │…│
│  페이지 추출  │ │🖍│                                 │                │ 1│
│  양식·서명    │ │✎│                                 │                │/n│
│  내려받기     │ └─┘ ← 떠 있는 도구 줄                │                │74%│
└──────────────┴──────────────────────────────────┴────────────────┴──┘
```

- **위 줄 탭**: "모든 도구"(왼쪽 도구 목록 열기), "읽기"(도구 창 닫고 본문만), "편집"(주석 도구 줄), "서명"(양식·서명 도구).
- **떠 있는 도구 줄**(페이지 왼쪽): 선택, 손(끌어 이동), 메모, 형광펜(▾ 밑줄·취소선), 펜(▾ 굵기·색), 글상자, 도형(▾ 사각형·타원·선·화살표), 지우개.
  고른 도구에 따라 색·굵기 작은 상자가 붙는다.
- **오른쪽 정보 창**: 책갈피(문서 목차, 눌러 이동) / 페이지(썸네일, 눌러 이동) / 메모(주석 목록 — 페이지·작성자·내용, 눌러 이동, 삭제) /
  필드(양식 칸 목록과 값). 맨 오른쪽 세로 줄에 이 창 단추들 + 쪽 번호 상자 + 이전/다음 + 배율 + 맞춤 + 보기 회전 + 확대/축소.
- **페이지 정리 화면**: 모든 쪽을 카드처럼 격자로(pdfcraft organize). 클릭/Ctrl/Shift로 고르고 위 도구 줄로 왼쪽·오른쪽 회전, 삭제,
  빈 페이지 넣기, 다른 PDF에서 넣기, 고른 쪽 추출(새 PDF 내려받기), 앞으로/뒤로. 끌어서 순서 바꾸기. "닫기"로 본문 보기.
- **찾기**: Ctrl+F 또는 위 찾기 상자 — 입력하는 대로 찾고 "n/m", Enter·Shift+Enter로 이동, 본문에 노란 표시.
- **읽기 전용 토큰**이면 편집 도구·정리·양식 입력을 숨기고 보기·찾기·내려받기만.
- 화면 크기: 좁으면 왼쪽 도구 목록·오른쪽 정보 창을 먼저 접는다(엑셀 홈 탭처럼 단계적으로).

## 2. 구조

### 2.1 그리기 — 브라우저의 pdf.js

- `pdfjs-dist`(이미 의존성, 4.2.67)를 편집기 번들에 넣고 worker는 `public/js/pdf.worker.mjs`로 복사한다.
- 쪽마다 canvas(배율·devicePixelRatio 반영, 보이는 쪽과 그 앞뒤만 그림 — 큰 문서 대비) + 글자 층(text layer: 선택·찾기·형광펜 위치) +
  우리 주석 층(SVG/DOM).
- 한글: cMap(`pdfjs-dist/cmaps`)과 표준 글꼴을 함께 내보내 글꼴이 안 들어 있는 한글 PDF(Adobe-Korea1)도 브라우저 글꼴로 그린다.
- 보안: `isEvalSupported: false`, PDF 안 자바스크립트 실행 안 함(enableScripting 끔).
- 파일에 이미 있던 주석·양식 모양은 pdf.js가 쪽과 함께 그린다(annotationMode). 1차에서 기존 주석은 보이기만 하고 고치지 않는다.

### 2.2 편집 내용 — Yjs 방(kind `pdf`)

다른 편집기와 같은 협업 방(room.ts)에 `pdf` 종류를 더한다. 원본 PDF는 그대로 두고, 바뀐 것만 Y.Doc에 둔다.

| 맵/배열 | 내용 |
|---|---|
| `pdfPages` (Y.Array) | 최종 쪽 순서: `{ id, src: { part: 'orig' \| 넣은 파일 id, index }, rotate: 0/90/180/270 }` 또는 빈 쪽 `{ id, blank: { w, h } }` |
| `pdfAnnots` (Y.Map) | 주석 id → `{ pageId, type: note\|highlight\|underline\|strike\|ink\|freetext\|rect\|ellipse\|line\|arrow\|signature\|stamp, rect, quads?, paths?, color, opacity, width, text?, fontSize?, image?(서명 PNG 자리), author, createdAt }` — 좌표는 원래 쪽의 PDF 좌표(회전 전) |
| `pdfForm` (Y.Map) | 양식 칸 이름 → 값(글자·체크·라디오·목록) |

- 실행 취소/다시 실행: Y.UndoManager(세 가지 모두).
- 다른 PDF 넣기(파일 합치기·파일에서 넣기): 그 파일은 `POST /api/view/pdf-part`로 올려 이 문서의 부속 파일(part)로 둔다
  (메모리 모드면 메모리, 문서 삭제·만료 때 함께 지움). 편집기는 `GET /api/view/pdf-part/:partId`로 받아 pdf.js로 그린다.
- 원본: `GET /api/view/pdf-source?token=`(편집기용 원본 바이트, canEdit 또는 열람 권한 확인).

### 2.3 저장 — 서버에서 pdf-lib로 (flushToStore / getCurrentBytes)

1. 원본을 pdf-lib로 연다(**원본 객체를 그대로 고친다** — 새 문서에 쪽을 복사하면 양식·책갈피가 끊기므로).
2. `pdfPages` 순서대로 쪽을 다시 배치: 지운 쪽 제거, 순서 바꾸기(같은 쪽 객체를 다시 끼움), 회전(`/Rotate`), 빈 쪽 추가,
   넣은 파일의 쪽은 `copyPages`로 복사(그 파일의 양식은 1차에선 유지하지 않음 — 쪽 내용·주석만).
3. 주석은 **PDF 표준 주석**으로 쓴다(다른 PDF 뷰어에서도 보이고 고칠 수 있게): Text(메모), Highlight/Underline/StrikeOut(QuadPoints),
   Ink, FreeText, Square/Circle, Line(화살표 끝 모양), Stamp(서명·도장 그림 — 그림을 모양 스트림(AP)에 넣음).
   모든 주석에 모양 스트림을 만든다. FreeText의 한글은 동봉 글꼴(Pretendard, assets/fonts)을 fontkit으로 넣는다(부분 글꼴).
4. 양식: `pdfForm` 값을 pdf-lib form으로 넣고, 한글이 있으면 Pretendard로 모양을 다시 만든다.
5. 저장 결과가 곧 문서 원본(다른 종류처럼 `saveOriginal` → 보기용 pdf 갱신). 내려받기는 `getCurrentBytes`.
6. **페이지 추출(나누기)**: `POST /api/view/pdf-extract { pages:[pageId…] }` → 위와 같은 과정으로 고른 쪽만 담은 새 PDF를 내려준다
   (문서는 그대로).
7. 변경 기록(`GET /api/view/changes`): 주석 추가·삭제, 쪽 정리, 양식 값 — 다른 종류와 같은 모양으로 간단히.

### 2.4 연결

- `EDITABLE_EXTS`에 pdf, `editorPathFor('pdf') = /editor-pdf.html`, 읽기 전용 편집기 허용 목록, edit.ts 허용 확장자, `kindOfExt`.
- PDF 업로드는 변환이 없으니(통과 복사) 바로 `editReady`로 표시해 기다림 없이 편집기를 연다.
- build-editor.mjs에 `src/client/editor-pdf.ts` 진입점.
- 향기랩(calc-site tools): 받는 확장자에 `.pdf`, 나머지 흐름(업로드 → 토큰 → editorUrl, ← 돌아가기, 진행 게이지)은 그대로.
- 8000(유지보수 시스템)도 같은 코드라 PDF가 편집기로 열리게 된다 — 그쪽 화면이 viewerUrl을 쓰는지 editorUrl을 쓰는지 확인하고,
  보기 화면을 쓰고 있으면 그대로 둔다(영향 없음 확인 후 반영).

## 3. 단계 (각 단계마다 시험 → 운영 반영 → 운영에서 확인)

1. **보기·찾기**: kind `pdf` 방, 원본 내려주기, 편집기 틀(위 줄·도구 목록·정보 창·오른쪽 줄), 연속 스크롤·확대·맞춤·회전,
   썸네일·책갈피, 찾기. 향기랩에서 PDF 열기 시작.
2. **주석**: 떠 있는 도구 줄의 메모·형광펜/밑줄/취소선·펜·글상자·도형·지우개, 메모 창, 실행 취소, 저장 시 표준 주석.
3. **페이지 정리**: 정리 화면, 회전·삭제·빈 쪽·순서·다른 PDF 넣기·파일 합치기·추출.
4. **양식·서명**: 양식 칸 입력·필드 창, 서명 그리기/그림 넣기, 날짜·글자 도장.

## 4. 시험

- 단위: 저장(쪽 순서·회전·삭제·빈 쪽·넣은 쪽, 각 주석 종류가 pdf-lib/pdf.js로 다시 읽히는지, 한글 FreeText·양식, 추출),
  방 시딩·변경 기록.
- 브라우저(Playwright, 시험 서버 8124): 한글 PDF(글꼴 포함/미포함) 표시, 찾기, 각 주석 그리기→저장→다시 열기, 정리 화면 조작,
  양식 입력·서명, 읽기 전용, 화면 폭별 배치. 저장 파일은 서버 쪽 pdf.js로 다시 열어 주석·쪽 수·글자 확인.
- 회귀: `npm test`, `verify:xlsx`, `verify:pptx`, 워드 리본 e2e — 기존 편집기·보기 화면이 그대로인지.

## 5. 범위 밖(다음 단계)

PDF 안 글자 직접 고치기, OCR, 가리기(redaction), 암호 걸기·풀기, 압축, 다른 형식으로 변환, 인증서 서명, 기존 주석 고치기,
여러 사람 동시 편집 화면(구조상 가능하지만 1차 시험 범위에서 뺌), 레이어 켜고 끄기.
