암호가 걸린 PDF

이 문서를 열려면 비밀번호가 필요합니다.

암호·권한

허용할 것

저장할 때 AES-256으로 잠급니다. 비밀번호는 저장되지 않으니 잊지 않게 따로 적어 두세요.

압축

그림을 쪽에 보이는 크기에 맞는 해상도로 줄여 파일을 작게 합니다. 글자·선은 그대로입니다.

글자 인식(OCR)

스캔한 쪽처럼 글자가 그림으로만 있는 쪽을 읽어, 찾기·글자 고르기·복사가 되게 합니다(한국어·영어). 이 브라우저에서 읽으므로 문서가 밖으로 나가지 않습니다.

변환

지금 편집한 상태 그대로 바꿉니다.

다른 파일을 PDF로

워드·엑셀·파워포인트·한글·그림 파일을 PDF로 바꿔 내려받습니다. 지금 문서에 쪽으로 넣으려면 페이지 정리의 ‘파일에서 넣기’를 쓰세요.

인증서 서명

지금 편집한 상태를 인증서로 전자서명한 PDF를 내려받습니다. 문서 자체는 바뀌지 않습니다.

인증서와 비밀번호는 서명하는 동안에만 쓰고 저장하지 않습니다. 서명한 뒤 파일을 고치면 서명이 깨집니다. 암호를 걸도록 해 둔 문서는 서명할 수 없습니다.
